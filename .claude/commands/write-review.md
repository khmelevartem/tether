Используя гайды проекта, проведи ревью PR <PR number>. 
Если вместо PR пользователь отправил номер issue, то найди связанный с issue PR и проведи его ревью.
Будь внимателен, придирчив в части смыслового наполнения. 
Не обращай внимания на оформление, если оно прямо не прописано в гайде.
По завершении опубликуй ревью в PR через `gh pr review <PR number> --comment --body "..."`.
