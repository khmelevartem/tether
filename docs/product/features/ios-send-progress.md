## Why

Counterpart of the Android send/progress feature on iOS. Required for MVP.

## What it does (sketch)

- User taps a device on the list, picks a file via the iOS picker, sees a progress screen, gets a clear success/failure outcome.
- Cancel during transfer is visible and works.
- Behavior matches the Android equivalent so the cross-platform feel is preserved.
